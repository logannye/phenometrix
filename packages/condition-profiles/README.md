# PhenoMetrix condition demo profiles

This package contains versioned, immutable research-demo views over existing
measurement protocol packs. A condition profile does not rename an engineering
measurement as clinically validated and does not introduce a diagnostic or
treatment claim.

The first profile, `UNILATERAL_FACIAL_MOVEMENT_PROFILE`, allowlists six existing
face outcomes for a two-session, page-memory-only repeatability demonstration.
The affected side is participant-asserted and remains unverified. The profile
does not infer laterality, reproduce a facial-grading scale, or interpret a raw
session difference as health change.
