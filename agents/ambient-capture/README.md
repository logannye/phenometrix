# Ambient Capture

## Goal

Create one consented, versioned ObservationV3 from technically measurable
moments in an ordinary local conversation. The condition demo invokes this
same capability twice to obtain two genuinely live observations.

## Implemented behavior

- request and calibrate voice and face independently;
- accept compact, media-free derived frames from worker boundaries;
- screen evidence into qualified voice segments and five-second face bins;
- run the frozen 27-metric deterministic registry;
- emit one measured or specifically withheld outcome per metric;
- preserve exact window, processor, track, algorithm, protocol, and consent
  provenance; and
- dispose media and transient state before report display.

There are no prompted microtasks in the current application. Failure of one
modality does not force the other modality to fail. Camera and microphone are
requested for both demo captures. The microphone remains a generic independent
lane and contributes to each 27-outcome report, even though the condition
profile later selects only six face outcomes.

## Hard boundary

Ambient Capture does not interpret conversation content, compare history,
diagnose, generate narrative conclusions, recommend action, persist data, or
retain evidence clips. Native media and high-dimensional processing
intermediates cannot enter its observation contract. It does not infer or
verify the participant's affected side. Acceptance of one completed
ObservationV3 as a page-memory reference belongs to Personal Trajectory, not
this capability.
